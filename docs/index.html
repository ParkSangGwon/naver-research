만든 사람 박상권 (ted)

Claude가 네이버 블로그를 검색하고 본문 전문까지 읽게 해 주는 스킬입니다.

맛집·여행·제품 후기처럼 한국 사람들의 실사용 경험은 대부분 네이버 블로그에 있습니다. 그런데 Claude는 기본 상태로는 그 글을 열지 못합니다. 이 스킬을 설치하면 "블로그 후기 모아줘"라고 말하는 것만으로 검색, 본문 읽기, 상위노출 분석까지 해 줍니다.

최근 일주일 사이 후기 15건 중 5건이 툇마루 이야기일 만큼 압도적이에요.

시그니처는 흑임자 크림을 올린 툇마루커피이고, 화요일은 쉽니다.

바다를 보며 조용히 앉고 싶다면 사근진해변의 백야커피, 아이와 간다면 공간이 넓은 346커피스토리가 편하다는 후기가 많았어요.

설치

어디서 쓰시나요?

저장소는 하나이고 설치 방법만 다릅니다.

  1. Claude 데스크톱 앱에서 저장소를 마켓플레이스로 추가합니다.

    왼쪽 사이드바 › 사용자 지정 › 플러그인 탭 › 오른쪽 위 + 추가 › 마켓플레이스 추가 › 저장소에서 추가

    URL 칸에 아래 주소를 붙여 넣고, 목록에 뜬 "…사용"을 고른 뒤 동기화를 누릅니다.

    https://github.com/ParkSangGwon/naver-research

  2. 목록에 나온 Naver research 옆의 추가를 누릅니다.

    "코드를 실행하는 구성 요소가 포함되어 있습니다" 안내가 뜨면 계속을 누릅니다. 네이버에 접속하는 작은 스크립트가 들어 있어서 뜨는 안내입니다.

  3. 네이버를 허용 목록에 넣습니다.

    왼쪽 아래 내 이름 › 설정 › 기능 › 코드 실행 및 파일 생성

    추가 허용 도메인 칸에 아래 두 개를 하나씩 넣고 그때마다 추가를 누릅니다.

    *.naver.com
    *.pstatic.net

    같은 화면의 "클라우드에서 코드 실행"과 "외부 네트워크 접속 허용"은 켜져 있어야 합니다.

  4. 새 대화를 열어 써 봅니다.

    설정을 바꾸기 전에 열어 둔 대화에는 반영되지 않습니다.

회사 계정(Team·Enterprise)은 네트워크 설정을 관리자만 바꿀 수 있습니다. 관리자에게 위 두 도메인을 허용해 달라고 요청하세요.

  1. 터미널에서 node --version을 쳐서 v18 이상인지 확인합니다. 안 나오면 nodejs.org에서 LTS를 설치합니다.

  2. 터미널에서 아래 두 줄을 실행합니다.

    claude plugin marketplace add ParkSangGwon/naver-research
claude plugin install naver-research@naver-research

  3. Claude Code를 새로 열어 써 봅니다.

네이버 API 키 등록 (선택 · 뉴스·대량 수집·쇼핑용)

키가 없어도 블로그 검색, 본문 읽기, 상위노출 분석, 이미지 받기는 됩니다. 키가 필요한 기능을 쓰는 순간 스킬이 발급 방법을 안내하며 멈춥니다.

  1. developers.naver.com/apps에서 애플리케이션을 등록합니다. 사용 API는 "검색"을 고릅니다.
  2. 발급된 Client ID와 Client Secret을 ~/.config/naver/.env 파일에 저장합니다.
NAVER_CLIENT_ID=발급받은_ID
NAVER_CLIENT_SECRET=발급받은_Secret

무료 사용량은 하루 25,000회입니다.

문제가 생기면

Claude 앱에서 네이버에 접속할 수 없다고 나와요

허용 도메인 단계가 빠졌거나, 설정을 바꾸기 전에 열어 둔 대화에서 쓴 경우입니다. 두 도메인이 목록에 있는지 확인하고 새 대화를 여세요. 이때 Claude가 Chrome 브라우저 권한을 달라고 하면 거부해도 됩니다.

새 버전은 어떻게 받나요?

Claude 앱은 사용자 지정 › 플러그인 › Naver research 화면의 업데이트를 누릅니다. Claude Code는 claude plugin marketplace update naver-research 뒤 claude plugin update naver-research@naver-research를 실행합니다.

제목이나 블로거명이 비어 있거나 본문을 못 찾아요

제목이 비면 네이버가 검색 화면 구조를 바꾼 경우이고, 본문을 못 찾으면 비공개나 삭제된 글입니다. 저장소에 알려 주시면 고치겠습니다.
