Claude가 네이버 블로그를 검색하고 본문 전문까지 읽게 해 주는 스킬입니다.

맛집·여행·제품 후기처럼 한국 사람들의 실사용 경험은 대부분 네이버 블로그에 있습니다. 그런데 Claude는 기본 상태로는 그 글을 열지 못합니다. 이 스킬을 설치하면 "블로그 후기 모아줘"라고 말하는 것만으로 검색, 본문 읽기, 상위노출 분석까지 해 줍니다.

Claude에게 맡기기

Claude 앱 대화창에 아래 프롬프트를 붙여 넣으면 Claude가 설치 순서를 한 단계씩 안내합니다. 플러그인 추가와 설정 변경은 앱 화면에서 직접 눌러야 해서, Claude는 다음에 누를 곳을 알려 주고 기다립니다.

naver-research 스킬 설치를 도와줘. 플러그인 추가와 설정 변경은 내가 직접 해야 하니까, 아래 순서를 한 번에 한 단계씩만 안내하고 내가 "했어"라고 하면 다음 단계로 넘어가줘. 화면에 안내한 메뉴가 안 보인다고 하면 비슷한 메뉴를 같이 찾아줘. 1. 왼쪽 사이드바 "사용자 지정" > "플러그인" 탭 > 오른쪽 위 "+ 추가" > "마켓플레이스 추가" > "저장소에서 추가"를 고르고, URL 칸에 https://github.com/ParkSangGwon/naver-research 를 붙여 넣은 뒤 "동기화"를 누른다. 2. 목록에 나온 "Naver research"의 "추가"를 누른다. 코드를 실행하는 구성 요소가 있다는 안내가 뜨면 "계속"을 누른다. 3. 왼쪽 아래 내 이름 > "설정" > "기능" > "코드 실행 및 파일 생성"에서 "클라우드에서 코드 실행"과 "외부 네트워크 접속 허용"이 켜져 있는지 보고, "추가 허용 도메인"에 *.naver.com 과 *.pstatic.net 을 하나씩 추가한다. 4. 다 끝나면, 설정은 이 대화에 반영되지 않으니 새 대화를 열어 아래 문장을 보내 보라고 알려줘. naver-research 설치 확인해줘. 스킬로 '강릉 카페'를 3건만 검색해 보고, 막히면 무엇을 고쳐야 하는지 알려줘.

  2. 목록에 나온 Naver research 옆의 추가를 누릅니다.

    *.pstatic.net

Claude에게 맡기기

Claude Code를 열고 아래 프롬프트를 그대로 붙여 넣습니다. Node.js 확인, 플러그인 설치, 테스트 검색까지 Claude Code가 알아서 합니다.

https://github.com/ParkSangGwon/naver-research 의 naver-research 플러그인을 Claude Code에 설치해줘. 1. node --version 으로 Node.js 18 이상인지 확인해. 없거나 버전이 낮으면 https://nodejs.org 에서 LTS 설치 파일(macOS는 .pkg, Windows는 .msi)을 받아 설치하라고 안내하고, 설치 후 Claude Code를 완전히 껐다 켠 다음 이 프롬프트를 다시 보내라고 말한 뒤 멈춰. 2. claude plugin marketplace add ParkSangGwon/naver-research 를 실행해. 이미 추가돼 있으면 claude plugin marketplace update naver-research 로 최신화해. 3. claude plugin install naver-research@naver-research 를 실행해. 이미 설치돼 있으면 claude plugin update naver-research@naver-research 로 업데이트해. 4. ~/.claude/plugins/cache 아래에서 naver-research 의 scripts/naver.mjs 를 찾아, node <그 경로> search "강릉 카페" --count 3 --format md 로 검색 결과 3건이 나오는지 확인해. 5. 끝나면 결과를 짧게 알려주고, Claude Code를 새로 열어야 스킬이 잡힌다는 것과 바로 써 볼 예시 문장 두 개를 알려줘.
직접 하려면 (터미널 명령)

  1. 터미널에서 node --version을 쳐서 v18 이상인지 확인합니다. 안 나오면 nodejs.org에서 LTS를 설치합니다.

  2. 터미널에서 아래 두 줄을 실행합니다.

    claude plugin marketplace add ParkSangGwon/naver-research
claude plugin install naver-research@naver-research

  3. Claude Code를 새로 열어 써 봅니다.

네이버 API 키 등록 (선택 · 뉴스·대량 수집·쇼핑용)

키가 없어도 블로그 검색, 본문 읽기, 상위노출 분석, 이미지 받기는 됩니다. 키가 필요한 기능을 쓰는 순간 스킬이 발급 방법을 안내하며 멈춥니다.

Claude Code에게 맡기려면 아래 프롬프트를 보냅니다. 키 값은 채팅에 붙이지 말고 파일에 직접 넣으세요.

naver-research에 네이버 Open API 키를 등록하려고 해. 1. https://developers.naver.com/apps 에서 애플리케이션을 등록하고 키를 발급받는 순서를 알려줘. 사용 API는 "검색"이야. 2. ~/.config/naver/.env 파일이 없으면 NAVER_CLIENT_ID= 와 NAVER_CLIENT_SECRET= 두 줄만 있는 파일로 만들어줘. 이미 있으면 건드리지 말고 알려줘. 3. 키 값은 내가 직접 그 파일에 넣을게. 채팅으로 키를 달라고 하지 마.

직접 하려면 아래 순서를 따릅니다.

  1. developers.naver.com/apps에서 애플리케이션을 등록합니다. 사용 API는 "검색"을 고릅니다.
  2. 발급된 Client ID와 Client Secret을 ~/.config/naver/.env 파일에 저장합니다.
NAVER_CLIENT_ID=발급받은_ID
NAVER_CLIENT_SECRET=발급받은_Secret

무료 사용량은 하루 25,000회입니다.

새 버전은 어떻게 받나요?

Claude 앱은 사용자 지정 › 플러그인 › Naver research 화면의 업데이트를 누릅니다. Claude Code는 claude plugin marketplace update naver-research 뒤 claude plugin update naver-research@naver-research를 실행합니다.

제목이나 블로거명이 비어 있거나 본문을 못 찾아요

제목이 비면 네이버가 검색 화면 구조를 바꾼 경우이고, 본문을 못 찾으면 비공개나 삭제된 글입니다. 저장소에 알려 주시면 고치겠습니다.
